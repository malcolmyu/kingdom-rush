## 仍有差异

1. 开始背景、标志、地图和角色来自原素材，但按钮排版、模式说明、暂停和结算界面仍是自建布局，未做逐像素比较验收。
2. 近战寻敌、部分单位移动、飞弹命中时序、闪电与英雄技能效果有所简化。英雄等级按战役进度提升，尚未还原原版完整经验与技能树。
3. 还未实现全局天赋树、成就、云存档和后续关卡。地图显示原始世界及后续关卡位置；只有前三关可进入。
4. 在线托管默认保持原站点的私人访问范围，需要创建站点的 ChatGPT 账号登录。

后续提高保真度时，先针对一个差异录制原版与当前实现的同场景，再补效果或动画状态；不依靠修改全局血量来掩盖缺失机制。
